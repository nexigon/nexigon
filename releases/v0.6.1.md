# Nexigon Agent and CLI 0.6.1

Released 2026-10-21.

This security release responds to the compromise of eight eMudhra intermediate
certificate authorities. Anyone holding the keys of the six TLS intermediates
can impersonate any HTTPS server to clients that trust them. See the
[incident page](https://emudhra.we-have-a-problem.com/) for details.

## Changes

Agent and CLI connections to the Hub have always used the operating system's
trust store. Other HTTPS connections also trusted root certificates compiled
into the binary, including `emSign ECC Root CA - G3`, to which the compromised
intermediates chain. This affected pairing-key provisioning, `repositories`
commands, and OTLP export. Agent and CLI 0.6.1 verify all HTTPS connections
against the operating system's trust store only.

In addition, 0.6.1 rejects certificate chains that contain any of the
compromised intermediate keys, regardless of the trust store's contents.

## Upgrading

Upgrade the Agent on your devices and the CLI on your workstations. No
configuration changes are required.

Agent 0.6.1 protects its own connections, but most other software on your
devices uses the same operating system trust store. Update the
`ca-certificates` package in your device images so that it no longer trusts
`emSign ECC Root CA - G3` and, on older releases, `Comodo AAA Services root`.
On Yocto, the OpenEmbedded-Core recipe does not include a fix at the time of
writing. Until it does, exclude both roots in `/etc/ca-certificates.conf`
through a bbappend in your own layer.
